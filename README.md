# Olá, eu sou a Maísa 👋

**Analista de Dados | Analytics Engineer** · Rio de Janeiro, Brasil

Construo soluções de dados de ponta a ponta, do banco ao painel que a liderança usa para decidir. Hoje cuido dos painéis e indicadores de uma operação de **produção sob demanda (impressão DTG)** em duas fábricas, no RJ e em SP, num grupo de moda e varejo.

Antes da camada analítica fui **DBA**. Por isso me preocupo com performance de consulta, integridade e modelagem desde o começo.

### 🔧 O que eu faço
- **Modelagem de dados e ETL** em SQL Server, PostgreSQL e Power Query (star schema)
- **Painéis em Power BI** com DAX avançado, pensados para decisão e não só para visualização
- **Automações em Python** que substituem controles manuais em planilha
- **Apps internos** com FastAPI + PostgreSQL/Supabase, levando dado em tempo quase real para o chão de fábrica
- **IA aplicada a dados**: agentes e servidores MCP consultando a base de produção
